📸 Guia Prático: Adicionar Imagens ao Site

🎯 Objetivo: Mostrar exatamente onde colocar suas fotos e logo na fazenda

⏱️ Tempo estimado: 10-15 minutos

📱 Dificuldade: Muito fácil - não precisa programar nada!

1️⃣ Entender a Estrutura de Pastas

Seu site tem esta estrutura:

site-fazenda/ ├── index.html (Página inicial) ├── fazenda.html (A Fazenda) ├── carreiras.html (Carreiras) ├── cadastro.html (Cadastro) ├── css/ │ └── style.css ├── js/ │ └── script.js └── images/ ← PASTA PARA AS FOTOS (vazia por enquanto)

A pasta images/ é onde você vai colocar todas as suas fotos e logo. É como um "guarda-roupa" do site.

2️⃣ Quais Imagens Adicionar?

Aqui está um resumo de onde cada imagem vai aparecer:

📍 Página 🖼️ Imagem 📐 Tamanho Recomendado 💾 Formato
Todas as páginas Logo da fazenda 200x200 px PNG ou JPG
Página Inicial Banner hero (grande) 1920x1080 px JPG
Página Inicial Foto sobre a fazenda 600x400 px JPG
Página A Fazenda Fotos das atividades 400x300 px JPG
Página Carreiras Fotos da equipe/instalações 400x300 px JPG
⚠️ Importante: As dimensões acima são ideais. Mas a coisa mais importante é usar fotos REAIS da sua fazenda, não imagens genéricas de internet. Fotos autênticas vão muito mais profissionalismo!

3️⃣ Passo a Passo: Como Adicionar Imagens

🎬 PARTE A: Preparar as Imagens

1

Tire fotos da sua fazenda

Com seu smartphone está ótimo! Tire:

  • Foto aérea ou panorâmica da fazenda (banner)
  • Foto do gado/pasto
  • Foto da equipe
  • Foto das instalações
  • Logo da fazenda (se tiver)
2

Redimensionar as imagens

Use um site GRATUITO para reduzir o tamanho:

  • iLoveImg.com (mais fácil) → "Redimensionar" → arraste a foto → escolha tamanho
  • Canva.com → "Redimensionar imagem" → escolha tamanho
  • Photopea.com (Photoshop online grátis)

Por que redimensionar? Fotos muito grandes deixam o site lento. Reduzir para 800x600 px é ideal.

3

Salvar as imagens com nomes claros

Nomes recomendados (sem espaços, com hífen):

logo-fazenda.png banner-hero.jpg foto-gado.jpg foto-equipe.jpg foto-instalacoes.jpg foto-pasto.jpg

⚠️ Evite: "Foto 1.jpg", "IMG_2024.jpg", "sem nome.png" → nomes confusos!

🚀 PARTE B: Subir as Imagens no GitHub

4

Faça login no GitHub

Acesse: github.com e faça login

5

Entre no seu repositório

Clique em seu repositório "site-fazenda"

6

Navegue até a pasta images

Clique em images/ (você verá a pasta vazia)

7

Clique em "Add file" → "Upload files"

Arraste suas fotos para a área indicada

Ou clique em "choose your files" e selecione as imagens

8

Clique em "Commit changes"

Coloque uma mensagem: "Upload de imagens da fazenda"

Aguarde 1-2 minutos. As imagens estarão disponíveis!

4️⃣ Editar o HTML para Usar as Imagens

Agora você precisa avisar ao site onde estão as imagens. Vou mostrar onde editar cada arquivo:

📄 A) Página Inicial (index.html)

Para adicionar Logo no Menu:

Encontre esta linha:

<div class="logo">3M Agropecuária</div>

Substitua por:

<div class="logo"> <img src="images/logo-fazenda.png" alt="Logo 3M" style="height: 50px;"> </div>

Para adicionar Banner Hero (foto grande):

Encontre esta linha (procure por "hero"):

<section class="hero">

Edite a seção .hero no arquivo css/style.css:

Encontre:

.hero { height: 100vh; background: linear-gradient(135deg, var(--verde-escuro) 0%, var(--verde-principal) 100%);

Substitua por:

.hero { height: 100vh; background: linear-gradient(135deg, rgba(45, 80, 22, 0.6) 0%, rgba(45, 80, 22, 0.6) 100%), url('images/banner-hero.jpg') center/cover no-repeat;

O que faz: A imagem fica de fundo, com uma camada semi-escura por cima para o texto ficar legível.

Para adicionar Foto na Seção "Quem Somos":

Encontre esta linha (procure por "placeholder-img"):

<div class="placeholder-img"> <p>📷 Insira aqui uma foto da fazenda</p> </div>

Substitua por:

<img src="images/foto-gado.jpg" alt="Rebanho da 3M Agropecuária" style="width: 100%; border-radius: 15px; box-shadow: 0 10px 30px rgba(0,0,0,0.1);">

📄 B) Página A Fazenda (fazenda.html)

Para adicionar Mapa (vai ficar onde diz "Mapa"):

Encontre:

<div class="mapa-container"> <p>🗺️ Insira aqui o código embed do Google Maps</p> </div>

Substitua por um mapa real do Google Maps. Ver tutorial aqui

📄 C) Adicionar Logo em TODAS as Páginas

Você precisa adicionar a logo em 4 arquivos:

  • index.html
  • fazenda.html
  • carreiras.html
  • cadastro.html

Em cada um, encontre e edite:

<div class="logo">3M Agropecuária</div>

Por:

<div class="logo"> <img src="images/logo-fazenda.png" alt="Logo 3M Agropecuária" style="height: 50px;"> </div>

5️⃣ Método SUPER Fácil (Sem Editar Código)

💡 Se você não quer editar HTML: Use a plataforma Netlify!

Em vez de GitHub Pages, use Netlify.com (também 100% grátis):

1

Acesse: netlify.com

2

Clique em "Sign up" e faça login com GitHub

3

Arraste a pasta site-fazenda inteira na tela do Netlify

4

Netlify faz o upload automático E você consegue editar os arquivos direto lá (visual)

Vantagem: Você edita o HTML visualmente, sem mexer em código!

❓ Dúvidas Comuns

P: Qual é o melhor formato para fotos? JPG ou PNG?

R:

  • JPG = Para fotos (menor tamanho, qualidade boa) ✅ RECOMENDADO
  • PNG = Para logo com fundo transparente (maior tamanho)

P: A foto não aparece no site. Por quê?

R:

  • Verifique o caminho: images/nome-da-foto.jpg (sem barra inicial /)
  • Certifique-se que a imagem está mesmo na pasta images/
  • Aguarde 2-3 minutos após fazer upload no GitHub
  • Limpe o cache do navegador: Ctrl+Shift+Delete

P: As fotos ficarão muito pesadas?

R: Não! Se você redimensionar para ~800x600 px e converter para JPG, cada foto fica ~50-200 KB. Totalmente normal.

P: Posso usar fotos de sites tipo Shutterstock?

R: Melhor NÃO. Fotos genéricas parecem "fake". SUAS fotos reais são MUITO melhores para credibilidade!

P: Quantas fotos devo adicionar?

R: O mínimo recomendado:

  • 1 logo
  • 1 banner grande (página inicial)
  • 3-4 fotos do dia a dia (gado, equipe, instalações)
Total: 5-6 imagens. Mais é melhor, mas não é obrigatório!

Tudo super simples, sem necessidade de programação avançada!
